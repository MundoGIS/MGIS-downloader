Ladda ner Höjddata (Markhöjdmodell)

Här kan du ladda ner Markhöjdmodell (Laserdata). Dessa filer är ofta i .tif format. Du kan välja att ladda ner för hela Sverige (alla filer) eller rita ett område i kartan.
Varning: Använd antingen ett token genererat i API Manager (apimanager) eller ett systemkonto från Geotorget. Token måste ha rätt scopes för STAC (collections/assets).

Viktigt: Använd ett token genererat i API Manager eller ett systemkonto från Geotorget. Token måste ha rätt scopes för STAC (collections/assets).

Filen kan vara i EPSG:4326, EPSG:3857 eller EPSG:3006. Vi konverterar automatiskt till WGS84 innan sökningen.
Om du väljer ett län används dess gräns i stället för ritad polygon.

Ingen geometri vald.

Rita en polygon för att begränsa nedladdningen, eller lämna tomt för hela Sverige.
